# Ashok Kunchala — Portfolio

A responsive portfolio using the yellow, cyan, bold-border style from the supplied UI video. Content and portrait are from Ashok's existing public portfolio.

## Run

From `/workspace/MAMA`, run `npm run dev` (Node and Python 3 required). The app runs on port 3000. There are no third-party runtime dependencies or build steps; deploy `index.html`, `style.css`, `app.js`, and `assets/` to any static host.

## Features

Responsive navigation, persistent light/dark theme, interactive career chapters, global client map, skills, Anvesa project, services, journal links, and contact form. The contact form prepares a message in the visitor's email app; it does not send through a backend.

`portfolio-download/` contains the original site archive. It is reference material and is not required to deploy the redesign. `npm run check` checks JavaScript syntax.
